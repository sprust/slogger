# Proposal

## Why

У SLogger нет страницы, которая коротко объясняет, что делает система и как она устроена. README подробный, но рассчитан на того, кто разворачивает установку. Людям без доступа к панели показать нечего. Нужна публичная страница-презентация на корневом адресе `/`, которая показывает работу системы теми же компонентами, что и админка, на демо-данных.

## What Changes

- Лендинг занимает корневой адрес `/`: открывается без входа и не делает запросов к API, пока гость не входит в панель. Страница `/login` удаляется: вход идёт через окно на лендинге по кнопке «Open panel», а все прежние переходы на `/login` ведут на `/` с открытым окном.
- На публичных маршрутах нет шапки и прокрутки панели: страница стоит по центру с отступами по бокам и прокручивается обычным скроллом. У страницы своя верхняя строка с названием и ссылкой на вход в панель.
- Страница на английском по умолчанию с переключением на русский, в сухом тоне, из разделов:
  1. Что это: назначение системы.
  2. Поиск трейсов: список трейсов с рабочей панелью фильтров на демо-данных, данные трейса, примеры поиска по ненормализованным `data` (вложенные поля, массивы значений и объектов, null, наличие поля).
  3. Трейс и дерево вызовов: демо-дерево на `TraceTreeRowView` с показателями трейсов, сквозное дерево нескольких сервисов. Профилирование не показывается.
  4. Графики: количество, длительность, память и CPU с перцентилями на `TraceTimelineChart`.
  5. Метрики приёма: сколько трейсов сервис прислал, принял в буфер и записал, на `TraceMetricsChart`.
  6. Смотрители и уведомления: правило → инцидент → события на `IncidentEventsTable` → каналы Telegram, Slack, JSON.
  7. MCP: что это, сценарии вопросов с цепочками инструментов, команда подключения.
  8. Путь данных: клиент → TCP-приёмник → буфер → слияние → ClickHouse, схема на vue-flow.
  9. Устройство и хранилища: рантайм SConcur, роли ClickHouse, MongoDB, MySQL, RabbitMQ, Redis, автоочистка.
  10. Установка: клонирование, env-файлы, `make setup`, пользователь и сервис.
  11. Отправка трейсов: протокол сокета, порт по умолчанию, формат сообщения с примерами.
- Все данные на странице — статические демо-данные из кода фронтенда, без обращения к установке.
- Тексты лежат отдельно от разметки, по объекту на язык; в верхней строке — переключатель языка и ссылка на репозиторий на GitHub. На странице входа появляется ссылка на лендинг.

## Capabilities

### New Capabilities

- `landing-page`: публичная страница-презентация на `/` и вход в панель через неё: доступ без входа, отсутствие запросов к API, состав разделов, сценарии MCP, демо-данные, стабильная раскладка.

### Modified Capabilities

Нет.

## Impact

- Фронтенд:
  - `frontend/src/utils/router.ts` — лендинг на `/` с признаком публичности, без маршрута `/login`, перенаправление неавторизованных на `/` с окном входа; `utils/handleApiRequest.ts` и `components/Header.vue` — переходы на лендинг вместо `/login`; `components/Login.vue` удалён;
  - `frontend/src/App.vue` — на публичных маршрутах своя раскладка без шапки и `el-scrollbar`;
  - новая папка `frontend/src/components/pages/landing` — страница, разделы, демо-данные, тексты.
- Перевод на props ещё четырёх частей агрегатора без изменения поведения: таблицы трейсов (`TraceTracesTableView`), просмотра данных трейса (`TraceAggregatorTraceDataNode`), строк условий по полям данных (`TraceAggregatorTracesCustomFields`) панели выбранных типов, тегов и статусов (`FilterTagsBarView`), панели данных выбранного трейса в дереве (`TraceDetailView`) и таблицы смотрителей (`WatcherListView`). Логика условий по полям данных выносится из store в отдельный модуль.
- Зависит от change `landing-reusable-components`: использует `TraceTreeRowView`, слот `#row` виртуального списка, `TraceTimelineChart`, `TraceMetricsChart`, `IncidentEventsTable`, `incidentEventColumns.ts`. Без изменений использует `TraceItemMetrics`, `TraceId` и JSON-вьюер.
- `app/Modules` и слои Deptrac не затрагиваются, бэкенд, API и OpenAPI не меняются. Публичный маршрут отдаёт тот же `index.html`, что и остальные маршруты SPA.
- Новых зависимостей нет: `vue-flow`, `chart.js` и Element Plus уже есть.
