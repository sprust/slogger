# Spec Delta

## Purpose

Воспроизводимое описание API SLogger для документации и генерации frontend-клиента на основе действующих запросов и ответов приложения.

## ADDED Requirements

### Requirement: Совместимая генерация API

Штатная команда SHALL генерировать admin-api в прежние public/private файлы, сохраняя маршруты, авторизацию, поля и статусы существующего API. Ошибка генерации SHALL возвращать ненулевой код.

#### Scenario: Полная генерация
- **WHEN** разработчик запускает генерацию схем
- **THEN** обновлены public/private файлы admin API и TypeScript-клиент собирается без изменения HTTP-контрактов

### Requirement: Типизированные контракты

Генератор SHALL поддерживать nullable enum, объединения ресурсов, пустой объект, корневой массив запроса и явно объявленные статусы ответа без подмены их универсальными строками или объектами.

#### Scenario: Nullable enum
- **WHEN** ответ содержит nullable enum
- **THEN** схема описывает допустимые enum-значения и null

#### Scenario: Варианты ресурса и список запроса
- **WHEN** описаны union ресурсов и запрос с корневыми правилами массива
- **THEN** схема использует oneOf для ответа и массив с типизированными элементами для запроса

#### Scenario: Явный статус
- **WHEN** endpoint объявляет успешный статус, отличный от 200
- **THEN** схема содержит именно объявленный статус
