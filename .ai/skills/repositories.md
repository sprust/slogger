# Репозитории SLogger

Читать перед созданием/расширением репозитория вместе с
[правилами](../rules.md). Существующие SConcur MongoDB и ClickHouse клиенты,
пакетные запросы и фильтры сохраняются.

- Repository содержит примитивы хранения, возвращает DTO/примитивы, не Model/Builder.
  Не внедряет другой repository. Сбор данных нескольких хранилищ — Domain Actions.
- Для новой Eloquent-сущности переиспользовать существующий подход модуля. Когда
  нужен общий построитель запросов, `BuilderMaker` отвечает только за фильтры и
  сортировку, не `with`/`select`; они остаются в read-repository.
  PHPDoc maker — `Builder|Model` для IDE, типизированный по конкретной модели.
- Один `when` на поле фильтра, условие `!== null`. Порядок сортировки задаёт
  вызывающий код. Одна фиксированная сортировка — boolean; несколько — список
  typed SortParameters(field enum, direction enum), без параллельных boolean-флагов.
  При переходе на список обновить все call sites; не добавлять неявную сортировку.
- Не вводить RawRepository/DetailRepository ради шаблона и не делить все текущие
  репозитории на read/write. Если задача требует Raw-представление, оно соответствует
  полям модели без relations и вычислений; mapping private, `findOne` nullable,
  `findMany` возвращает typed list. Detail — только для реально нужного представления.
- Новая запись Eloquent: явные присваивания, `saveOrFail`, вернуть id; обновление
  — явные присваивания. Точечный update одного-двух полей через query builder допустим.
  У SConcur MongoDB нет Eloquent `saveOrFail`; использовать существующие операции.
- Full-update требует все поля; partial-update различает «не передано» и null.
  Сохранять известную семантику существующего endpoint; если для новой операции
  она не определена пользователем/контрактом, уточнить до реализации.
- `Find*Parameters` допускает необязательные nullable фильтры и пустые списки
  сортировки. У Create/Update/PartialUpdate defaults нет.
- Физическое удаление, история удалённых объектов и исходные timestamps
  сохраняются. Не исключать полезное поле текущего DTO ради совпадения шаблона.
- Проверка: тесты результата и состояния хранилища, `make check`.
